# Devitai 🤖✨

**Devitai** is a high-end boutique engineering agency specializing in **Autonomous AI Agents** and **Modern Software Architectures**. We forge technical solutions that combine artistic precision with artificial intelligence.

## 🚀 Key Features

- **Premium Bento Grid**: A high-end visual grid system showcasing our core services.
- **Representative Visuals**: CSS-only animations simulating code builds, AI orchestrators, and global data flows.
- **Full i18n Support**: Native multi-language support (ES/EN) using Astro's efficient routing.
- **Agentic Aesthetics**: A modern, dark-themed UI designed for a technical and premium audience.
- **Boutique Performance**: Built with Astro for lightning-fast loads and optimal SEO.

## 🛠️ Tech Stack

- **Framework**: [Astro 5](https://astro.build/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide Astro](https://lucide.dev/)
- **Typography**: [Outfit](https://fonts.google.com/specimen/Outfit) (Headers) & [JetBrains Mono](https://fonts.google.com/specimen/JetBrains+Mono) (Technical accent)
- **Deployment**: Optimized for static hosting (Netlify/Vercel)

## 📁 Project Structure

```text
/
├── src/
│   ├── components/
│   │   ├── common/      # Reusable UI elements (Logo, Switchers)
│   │   └── sections/    # Main landing sections (Hero, BentoGrid, TechStack)
│   ├── i18n/            # Translation dictionaries and utilities
│   ├── layouts/         # Main HTML document structure
│   ├── pages/           # Route definitions (Localized ES/EN)
│   └── styles/          # Global CSS and custom animations
├── public/              # Static assets and favicons
└── astro.config.mjs     # Astro and i18n configuration
```

## ⌨️ Development

All commands are run from the root of the project:

| Command | Action |
| :--- | :--- |
| `pnpm install` | Installs dependencies |
| `pnpm dev` | Starts local dev server at `localhost:4321` |
| `pnpm build` | Builds your production site to `./dist/` |
| `pnpm preview` | Previews your build locally |
